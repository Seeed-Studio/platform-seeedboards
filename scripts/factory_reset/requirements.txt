# Dependencies for the factory-reset / recover tools, installed by the
# wrapper scripts into scripts/factory_reset/.venv.
#
# pyOCD comes from the official package: the nRF54LM20A target support the
# former StarSphere-1024 fork carried was merged upstream (pyocd/pyOCD#1889,
# released in v0.44.0), and its JLink fix was superseded in v0.45.0
# (pyocd/pyOCD#1927). The fork never contained a flash fix: its flash
# algorithm is byte-identical to the official one.
#
# Known limitation: `pyocd flash` on nRF54LM20A faults because the builtin
# algorithm programs RRAM with the RRAMC write buffer unconfigured
# (pyocd/pyOCD#2016); the fix is pending in pyocd/pyOCD#2033. Bump this pin
# once that ships in a release and pyocd flash becomes usable. Until then
# nRF54LM20A flashing goes through the OpenOCD path (factory_reset_lm20a.*
# and nrf54lm20a-load); list/rtt/erase work fine. See
# Seeed-Studio/platform-seeedboards#69.
#
# KEEP IN SYNC with _ensure_pyocd_installed() in
# builder/board_build/nrf/nrf_build.py, which pins the same version
# for the PlatformIO upload path.
